Claude Code mod
Stoke your cache while working elsewhere

Keeps the prompt cache warm so a meeting does not cost you the conversation.

Claude Code re-sends the whole conversation every request and relies on the cache, which expires after 5 idle minutes. Bunsen sends one small background request, a stoke, just before it expires. Nothing lands in your transcript.

$203saved in my first 3 weeks, as sessions returned to a warm cache
2.9×saved for every $1 spent on 1,612 stokes
All the savings, none of the bloat.nothing added to the transcript or the context
ButlerClaude Code plugin
Everything in its place. Mind the essentials. Enhancements at your service.

Prices every plugin you run and disables the ones you never use.

Every enabled plugin injects its descriptions into every request, and nothing in Claude Code shows the cost. Butler measures it, protects anything that leaves no usage trace, enforces governed-over-experimental precedence, and keeps marketplaces current.

86% lessalways-on plugin context per request: ~32.7K tokens down to ~4.5K
0plugins ever deleted. It only disables, so every cut is reversible
~0.4 ssession-start status line keeps the cost in view
Excel MCPMCP server
The Excel you have open, plus the full power of Claude Code

Claude Code works inside your live workbook, with the rest of your toolbelt in the same conversation.

It attaches to the running Excel, so it sees unsaved edits, hidden sheets, VBA, macros and Power Query. Large writes preview first, every write is journalled for undo, and a SharePoint file refuses writes until you acknowledge colleagues may be editing it.

215Kvalues copied between workbooks in one call, none in the model's context
15%smaller fixed tool surface than when first measured
24%smaller typical tool responses than when first measured
M365 MCPMCP server
A thin server over the CLI for Microsoft 365

Four generic tools reach roughly 900 Microsoft 365 commands.

Rather than hand-wrapping every command, it exposes status, login, help and run, and shells out to the m365 CLI you already have. Single sign-on is reused, so a warm session needs no new login.

~900CLI commands reachable
